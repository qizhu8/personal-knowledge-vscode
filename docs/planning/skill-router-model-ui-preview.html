Why run this?

PKM retrieval gives Agents durable access to your Skills, Notes, Scripts, and subscribed knowledge. The Router Workbench above controls retrieval; Agent projection and runtime configuration continue below.

Prepare the reference model

This is an explicit setup action. Search serving will remain offline-only and will never download weights.

huggingface-cli download intfloat/multilingual-e5-small --revision 614241f622f53c4eeff9890bdc4f31cfecc418b3 --local-dir ~/pkm-envs/models/multilingual-e5-small
If Hugging Face is unavailable, close this dialog and choose a complete local bundle instead. Exact + BM25 remain usable.
